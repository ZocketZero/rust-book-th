# The Rust Programming Language

_โดย Steve Klabnik, Carol Nichols, และ Chris Krycho พร้อมด้วยผลงานจากชุมชน Rust_

หนังสือฉบับนี้สมมติว่าคุณกำลังใช้ Rust 1.96.0 (เปิดตัวเมื่อ 2026-05-28) หรือใหม่กว่า ร่วมกับ `edition = "2024"` ในไฟล์ *Cargo.toml* ของโปรเจกต์ทั้งหมดเพื่อกำหนดค่าให้ใช้สำนวนของ Rust 2024 Edition ดูหัวข้อ [“การติดตั้ง” ในบทที่ 1][install]<!-- ignore --> สำหรับคำแนะนำในการติดตั้งหรืออัปเดต Rust และดู [ภาคผนวก E][appendix-e]<!-- ignore --> สำหรับข้อมูลเกี่ยวกับรุ่น (editions)

รูปแบบ HTML สามารถใช้งานทางออนไลน์ได้ที่
[https://doc.rust-lang.org/stable/book/](https://doc.rust-lang.org/stable/book/)
และใช้งานแบบออฟไลน์ผ่านการติดตั้ง Rust ด้วย `rustup`; รัน `rustup doc --book` เพื่อเปิดใช้งาน

นอกจากนี้ยังมีหนังสือฉบับ [แปลโดยชุมชน][translations] ในภาษาอื่นๆ อีกด้วย
